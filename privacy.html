プライバシーポリシー

最終更新日：2026年11月4日

1. このアプリについて

「Amane Itose Tools」は、YouTubeチャンネル「糸瀬あまね / Amane Itose」（https://www.youtube.com/@AmaneItose）の運営者が、自分のチャンネルを管理するために使う個人用ツールです。一般には配布しておらず、利用者は運営者本人だけです。次の2つの機能があります。

  • 完成した動画を、運営者のチャンネルへ非公開でアップロードする。
  • 運営者のチャンネルに届いたコメントを取得し、返信の下書きを作る。返信は、運営者本人が画面で承認操作をしたときだけ、1件ずつ投稿する。

2. 取得する情報

運営者がGoogleアカウントでログインして許可した範囲で、YouTube Data API v3 を通じて次の情報を取得します。

  • 運営者のYouTubeチャンネルの情報（チャンネルID、チャンネル名）
  • 運営者のチャンネルの動画の情報（動画ID、タイトル、説明）
  • 運営者のチャンネルの動画に付いたコメントと返信（本文、投稿者の表示名とチャンネルID、投稿日時）
  • Googleのログイン情報（OAuthのアクセストークンとリフレッシュトークン）

利用する権限（スコープ）は次の2つです。

  • https://www.googleapis.com/auth/youtube.upload：動画の非公開アップロード、サムネイルと字幕の設定
  • https://www.googleapis.com/auth/youtube.force-ssl：コメントの取得と、運営者が承認した返信の投稿

3. 利用目的

取得した情報は、上の2つの機能を運営者本人が使うためだけに利用します。広告、販売、マーケティング、利用者の分析には使いません。

4. 保管場所と保管期間

取得した情報とログイン情報は、運営者本人のパソコンの中だけに保存します。運営者以外が管理するサーバーには保存しません。運営者がデータを削除するか、下の方法で許可を取り消すまで保管します。

5. 第三者への提供

取得した情報を、販売したり、広告目的で提供したり、他のアプリへ転送したりしません。ただし、返信の下書きを作るときは、対象のコメントの本文、動画のタイトルと説明などを、次のいずれかのAIに送ります。送信先での取り扱いは、それぞれのプライバシーポリシーに従います。

  • 運営者が契約しているAIサービス（Anthropic社のClaude）
  • 運営者のパソコン上で動くAI（外部へは送信しません）

AIが作るのは返信の下書きだけです。AIが自動で返信を投稿することはありません。

6. Googleのユーザーデータに関するポリシーへの準拠

Google API から受け取った情報の使用と、他のアプリへの転送は、限定的な使用（Limited Use）の要件を含む、Google API サービスのユーザーデータに関するポリシーに準拠します。

7. 許可の取り消しとデータの削除

  • Googleアカウントのサードパーティのアクセス権の管理から、このアプリの許可をいつでも取り消せます。
  • 保存したデータは、運営者のパソコン内のファイルを削除することで消せます。
